# 贡献者公约行为准则（Contributor Covenant Code of Conduct）

> 本文档为 [English 原文](../CODE_OF_CONDUCT.md) 的中文翻译版本。如有歧义请以英文原版为准。
>
> ⚠️ 本翻译仅供参考，所有法律效力以英文原文为准。

## 我们的承诺

作为成员、贡献者和领导者，我们承诺让参与我们社区的每一个人都享有无骚扰的体验，不论其年龄、体型、可见或不可见的残疾、族裔、性征、性别认同与表达、经验水平、教育水平、社会经济地位、国籍、个人外貌、种族、宗教、或性身份与性取向。

我们承诺，以有助于建立一个开放、热情、多元、包容、健康社区的方式行事和互动。

## 我们的标准

有助于为我们的社区营造积极环境的行为示例包括：

- 对他人展现共情和善意
- 尊重不同的意见、观点和经历
- 给予并优雅地接受建设性的反馈
- 对错误负责，向受我们错误影响的人道歉，并从经验中学习
- 不仅着眼于自身利益，更关注整个社区的最大利益

不可接受的行为示例包括：

- 使用性化语言或图像，以及任何形式的性关注或性挑逗
- 网络喷子（trolling）、侮辱性或贬损性评论、人身或政治攻击
- 公开或私下的骚扰
- 未经他人明确许可，公开他人的私人信息，例如物理地址或电子邮件地址
- 其他在专业场合中可被合理认为不当的行为

## 执行职责

社区领导者负责澄清并执行我们对可接受行为的标准，并将针对他们认为不当、具有威胁性、冒犯性或有害的任何行为，采取适当且公平的纠正措施。

社区领导者有权且有责任删除、编辑或拒绝不符合本行为准则的评论、提交、代码、wiki 编辑、issue 及其他贡献，并将在适当时沟通做出审查决定的原因。

## 适用范围

本行为准则适用于所有社区空间，并且当个人在公开场合正式代表社区时也适用。代表我们社区的示例包括使用官方电子邮件地址、通过官方社交媒体账户发布信息，或在线上或线下活动中担任指定代表。

## 执行

辱骂、骚扰或其他不可接受的行为，可向负责执行的社区领导者举报，联系邮箱：<info@nautechsystems.io>。
所有投诉将得到及时、公正的审查与调查。

所有社区领导者均有义务尊重任何事件举报者的隐私和安全。

## 执行指南

社区领导者在认定违反本行为准则的任何行为的后果时，将遵循以下"社区影响指南"：

### 1. 纠正

**社区影响**：在社区中使用不当语言，或表现出被视为不专业或不受欢迎的其他行为。

**后果**：来自社区领导者的私下书面警告，澄清违规的性质并解释为何该行为不当。可能会被要求公开道歉。

### 2. 警告

**社区影响**：通过单一事件或一系列行为违反规定。

**后果**：附带后果的警告，对继续此类行为的处理。在指定时间内不得与涉事人员互动，包括与执行行为准则的人员的未经请求的互动。这包括避免在社区空间以及社交媒体等外部渠道中互动。违反这些条款可能导致临时或永久封禁。

### 3. 临时封禁

**社区影响**：严重违反社区标准，包括持续的不当行为。

**后果**：在指定时间内临时禁止与社区进行任何形式的互动或公开沟通。在此期间，不允许与涉事人员进行任何公开或私下的互动，包括与执行行为准则的人员的未经请求的互动。违反这些条款可能导致永久封禁。

### 4. 永久封禁

**社区影响**：表现出违反社区标准的模式，包括持续的不当行为、对个人的骚扰，或对某类个人的攻击或贬损。

**后果**：永久禁止在社区内进行任何形式的公开互动。
