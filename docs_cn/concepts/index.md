# 核心概念

> 本文档为 [English 原文](../../docs/concepts/index.md) 的中文翻译版本。如有歧义请以英文原版为准。

本系列指南介绍 NautilusTrader 的核心组件、架构与设计。

## 概览（Overview）

平台的主要特性与目标使用场景。

## 架构（Architecture）

支撑平台的原则、结构与设计。

## Actors

`Actor` 是与交易系统交互的基础组件。本节涵盖其能力与实现细节。

## 策略（Strategies）

如何使用 `Strategy` 组件实现交易策略。

## 标的（Instruments）

可交易资产与合约的标的（instrument）定义。

## 合成标的（Synthetics）

用户自定义的标的，其价格通过对组成标的的价格执行数值表达式计算而来。

## 连续期货（Continuous Futures）

通过显式的展期表（roll table）将连续的期货合约拼接为一条经过调整的 K 线序列，包含四种调整模式、请求与订阅流程，以及 K 线中段（mid-bar）的展期边界策略。

## 数值类型（Value Types）

整个平台所使用的不可变数值类型（`Price`、`Quantity`、`Money`），包括其算术行为、精度处理以及类型特定的约束。

## 数据（Data）

交易领域的内置数据类型，以及如何使用自定义数据。

## 事件（Events）

驱动系统的事件类型：订单事件、持仓事件、账户事件与时间事件。涵盖处理器分发、从订单成交到持仓事件的因果链，以及订单到持仓的追溯。

## 期权（Options）

期权标的类型、由交易所提供的希腊字母（Greeks）流、带行权价范围过滤的期权链订阅，以及快照聚合。

## 希腊字母（Greeks）

通过两种路径获取期权希腊字母（delta、gamma、vega、theta）：通过 Rust/PyO3 的 `OptionGreeks` 类型获取交易所提供的实时希腊字母，以及使用本地 `GreeksCalculator` 进行 Black-Scholes 计算，支持冲击情景、贝塔加权与组合聚合。

## 自定义数据（Custom Data）

自定义数据系统在 Python 与 Rust 之间的工作方式：注册、持久化、Arrow 编码，以及通过 actor 与策略进行运行时路由。

## 订单簿（Order Book）

高性能订单簿、自有订单跟踪、用于净流动性的过滤视图，以及二元市场支持。

## 执行（Execution）

跨多个策略与多个交易所（每实例）的同时交易执行与订单管理，包含涉及的组件以及执行消息（命令与事件）的流转。

## 订单（Orders）

可用的订单类型、支持的执行指令、高级订单类型，以及模拟订单（emulated orders）。

## 持仓（Positions）

持仓生命周期、由订单成交聚合而来的状态、盈亏（PnL）计算，以及针对净额（netting）OMS 配置的持仓快照。

## 缓存（Cache）

`Cache` 是所有交易相关数据的中央内存存储。本节涵盖其能力与最佳实践。

## 消息总线（Message Bus）

`MessageBus` 实现组件之间的解耦通信，支持点对点、发布/订阅以及请求/响应模式。

## 账户（Accounting）

账户类型（现金、保证金、博彩）、`AccountBalance` 与 `MarginBalance` 数据模型、单标的与账户级保证金范围、策略查询 API、内置保证金模型，以及跨实盘交易所的适配器约定。

## 组合（Portfolio）

`Portfolio` 追踪跨策略与标的的所有持仓，提供持仓、风险暴露与绩效的统一视图。

## 报告（Reports）

执行报告、组合分析、盈亏核算，以及回测后运行分析。

## 日志（Logging）

针对回测与实盘交易的高性能日志系统，由 Rust 实现。

## 回测（Backtesting）

使用特定的系统实现对历史数据进行模拟交易。

## 可视化（Visualization）

用于分析回测结果的交互式 tearsheet，包括图表、主题、自定义选项，以及通过可扩展图表注册表实现的自定义可视化。

## 配置（Configuration）

配置结构体在 Python 与 Rust 之间的工作方式：默认值解析、`T` 与 `Option<T>` 约定、构建器模式，以及跨适配器与引擎共享的常见字段。

## 实盘交易（Live Trading）

无需更改代码即可将已回测的策略部署到实时市场，以及回测与实盘交易之间的关键差异。

## 适配器（Adapters）

为数据提供方与交易所开发集成适配器的要求与最佳实践。

## Rust

直接使用 `crates/` 实现，以纯 Rust 编写 actor、策略并运行回测与实盘交易。

## 确定性仿真测试（DST）

种子可回放执行的确定性约定、实现该约定的源码级接缝（seams）、强制执行该约定的 pre-commit 钩子，以及已知的范围边界。
